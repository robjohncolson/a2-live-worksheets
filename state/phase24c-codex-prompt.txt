## Task: Deep Handler Exploration + OS Callback Table Research (Phase 24C)

You are working on a TI-84 Plus CE ROM transpilation project. Phase 24A unlocked the ISR dispatch gate (block 0x000710 now reachable). Phase 24B discovered 45 new seed addresses and found that handler 0x08C331 runs 1000+ steps deep into OS code. Your job is to explore the deep handlers, trace memory writes to find the OS callback table initialization, and map the OS subsystems.

### Context

The ISR at 0x000710 reads a 24-bit callback pointer from RAM at 0xD02AD7 and calls it. Currently RAM is zeroed, so the callback goes to 0x000000 (reset). On real hardware, the OS boot initializes this pointer (and likely a table of handler addresses nearby) so the ISR dispatches to real event handlers.

Phase 24B Test 13 probed ROM handler table addresses. Key findings:
- **0x08C331**: Ran 1000 steps (hit max_steps), reached 0x06ACB2 — likely a major OS subsystem
- **0x061DB6**: Ran 109 steps, reached new block at 0x00586A
- **0x07C705**: Ran 86 steps, reached HALT — math library area
- **0x07C897**: Ran 270 steps, reached missing block — deeper math
