## Required test cases (use `describe`/`it` blocks)

### `describe('daysLeft')`
- `daysLeft('2026-04-13', '2026-05-07')` → 24
- `daysLeft('2026-05-07', '2026-05-07')` → 1
- `daysLeft('2026-05-08', '2026-05-07')` → 1
- `daysLeft('garbage', '2026-05-07')` → 1

### `describe('computeDailyDose')`
- `computeDailyDose(81, 24)` → 4
- `computeDailyDose(5, 1)` → 5
- `computeDailyDose(500, 1)` → 12 (clamped max)
- `computeDailyDose(10, 100)` → 3 (clamped min)
- `computeDailyDose(0, 24)` → 3 (floor)

### `describe('formulaWeight')`
- Empty state (`touchedFormulas: {}`), formula `'phat-sd'`:
  - Expected: `0.095 * 4 * (1 - 0.3) = 0.266` (use `expect(w).toBeCloseTo(0.266, 3)`)
- Touched state with `phat-sd` at `lastMastery = 0.8`:
  - Expected: `0.095 * 4 * (1 - 0.8) = 0.076` (use `toBeCloseTo`)
- Unknown formula (`'nonexistent-formula'`) returns `0`

### `describe('formulaMastery')`
- Empty state → returns `0.3` (BKT_INIT).
- `state.touchedFormulas['phat-sd'] = { lastMastery: 0.65 }` → returns `0.65`.

### `describe('recordFormulaTouch')`
- First touch, `correct=true`: creates entry with `lastMastery > 0.3`, `firstTouchedAt` set to a `YYYY-MM-DD` string.
- Second touch, `correct=false`: updates `lastMastery`, preserves `firstTouchedAt`.

### `describe('touchedFormulaCount')`
- Empty state, tier `'core'` → 0.
- After `recordFormulaTouch('phat-sd', true, state)` (phat-sd is core in the stub): returns 1 for `'core'`, 0 for `'regular'`.

### `describe('pickProbeForFormula')`
- For `'phat-sd'` (main curriculum): returns `{ formulaId: 'phat-sd', questionId: 'U5-L5-Q01', unit: 5, lesson: 5, tier: 'core' }`.
- For `'margin-error'` (supplement): returns `{ formulaId: 'margin-error', questionId: 'U7-L2-QS1', unit: 7, lesson: 2, tier: 'support' }`.
- For an unknown formula: returns `null`.

### `describe('pickDailyQueue')`
- With an empty state, `todayStr='2026-04-13'`, `examDateStr='2026-05-07'`: the returned `queue` has length `<= 4` (computeDailyDose(<=4 formulas in stub, 24 days) → 3 via min-clamp, or 4 if `remaining=4` days=24 gives 1 but clamped up to 3) AND every entry has `{ formulaId, questionId, unit, lesson, tier }` populated.
  - In this stub we have only 4 formulas total, so `remaining=4`, `days=24`, `ceil(4/24)=1`, clamped to 3. So `queue.length === 3`. Assert it.
- Given `state.dailyDose = { date: '2026-04-13', queue: [...] }` and calling with `todayStr='2026-04-13'`: the function returns the *same* queue (idempotent — does not regenerate).
- Given `state.dailyDose = { date: '2026-04-12', queue: [...] }` and calling with `todayStr='2026-04-13'`: returns a fresh queue with `date: '2026-04-13'`.

### `describe('coverage floor invariant')`
- Start from empty state. Confirm `pickDailyQueue` prioritizes untouched core/regular formulas (the first queue entry's formulaId is either `'phat-sd'` (core) or `'corr-r'` (regular), never `'slope-t'` (power) or `'margin-error'` (support)).
- After `recordFormulaTouch('phat-sd', true, state)` and `recordFormulaTouch('corr-r', true, state)`: the next `pickDailyQueue` (after nulling `state.dailyDose`) may pick power or support formulas (both core+regular are now touched).
