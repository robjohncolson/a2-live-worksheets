## Why v2 exists

v1 batched all 9 FRQs into one "Grade My Diagnostic" button — a big time commitment for students. v2 redesigns around these principles:

1. **Per-unit cards**, each with its own grading flow. Students complete units in any order.
2. **Mode toggle per unit**: `MCQ` (fast, client-side) / `FRQ` (deep, AI-graded) / `Both`.
3. **Immediate feedback**: MCQ is graded the instant the student clicks Check (zero API calls). FRQ grades on click too, but hits `/api/ai/grade` for one unit at a time.
4. **Per-unit "Show me what to focus on"** button runs an AI synthesis that combines MCQ results + FRQ grade + the AP Course Framework metadata for the unit → returns a prioritized focus-lessons list grounded in AP LO codes.
5. **Export / Import**: one "Export" button generates a self-contained HTML file that is BOTH a printable submission to the teacher AND a save file. Students without AI access still get value (MCQ results + printable artifact). An "Import" file input reads the same file back to restore state.

### FRQ grading fetch (use this shape)
```js
async function gradeFrq(unitNumber) {
  const gateId = window.GATE_IDS_SG[unitNumber];
  const question = questionById.get(gateId);
  const fullPrompt = window.stripFrqBoilerplateSG(question ? question.prompt : '');
  const state = getUnitState(unitNumber);
  const answer = (state.frqAnswer || '').trim();
  if (answer.length < 20) {
    setUnitGrade(unitNumber, { score: 'I', feedback: 'Please write a more complete response (at least 20 characters).' });
    return;
  }
  const prompt = window.buildReflectionPromptSG(unitNumber, fullPrompt, answer);
  const response = await fetch(`${window.RAILWAY_SERVER_URL}/api/ai/grade`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      scenario: {
        topic: 'Algebra 2 Diagnostic Study Guide',
        questionId: gateId,
        lessonContext: window.LESSON_CONTEXT_SG,
      },
      answers: { answer: answer },
      prompt: prompt,
    }),
  });
  if (!response.ok) throw new Error('Grading request failed');
  const result = await response.json();
  if (result.score === 'P' && Array.isArray(result.missing) && result.missing.length === 0) {
    result.score = 'E';
    result.feedback = 'Nice work — you covered the key ideas.';
  }
  setUnitGrade(unitNumber, result);
  persistState();
  submitFrqAnswer(unitNumber, answer, result); // best-effort, wrapped in try/catch
}
```

### Focus synthesis fetch
```js
async function runFocusSynthesis(unitNumber) {
  const state = getUnitState(unitNumber);
  const mcqResults = Object.keys(state.mcqResults || {}).map(function (qid) {
    const q = questionById.get(qid) || {};
    const lesson = parseLessonFromId(qid); // extract L\d+
    return {
      questionId: qid,
      lesson: lesson,
      correct: state.mcqResults[qid] === 'correct',
      selected: state.mcqAnswers[qid] || '',
      correctAnswer: q.answerKey || '',
      prompt: (q.prompt || '').slice(0, 400),
    };
  });
  const frameworkContext = (typeof UNIT_FRAMEWORKS !== 'undefined')
    ? window.getFrameworkContextSG(unitNumber, UNIT_FRAMEWORKS)
    : null;
  const prompt = window.buildFocusSynthesisPromptSG({
    unit: unitNumber,
    unitTitle: window.UNIT_TITLES_SG[unitNumber],
    unitTopic: window.UNIT_TOPICS_SG[unitNumber],
    mcqResults: mcqResults,
    frqAnswer: state.frqAnswer || '',
    frqGrade: state.frqGrade || null,
    frameworkContext: frameworkContext,
  });
  const response = await fetch(`${window.RAILWAY_SERVER_URL}/api/ai/grade`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      scenario: {
        topic: 'Algebra 2 Diagnostic Focus Synthesis',
        questionId: `SG-U${unitNumber}-FOCUS`,
        lessonContext: window.LESSON_CONTEXT_SG,
      },
      answers: { answer: 'Focus synthesis request' },
      prompt: prompt,
    }),
  });
  if (!response.ok) throw new Error('Focus synthesis request failed');
  const result = await response.json();
  setUnitFocus(unitNumber, result);
  persistState();
}
```

Note: the server's `/api/ai/grade` endpoint passes `prompt` through to the LLM and returns whatever JSON the LLM produced. The focus synthesis prompt asks for a specific shape, so the client gets `{priority, overallSummary, focusLessons: [...], synthesisNote}`. Defensive-parse — if the result doesn't match, fall back gracefully.

## MCQ probe selection (client-side, per unit)

```js
function buildProbesForUnit(unitNumber) {
  const unitPrefix = 'U' + unitNumber + '-L';
  const mcByLesson = {};
  for (const q of EMBEDDED_CURRICULUM) {
    if (q.type !== 'multiple-choice') continue;
    if (!q.id.startsWith(unitPrefix)) continue;
    const m = q.id.match(/^U\d+-L(\d+)-Q\d+/);
    if (!m) continue;
    const lesson = parseInt(m[1], 10);
    (mcByLesson[lesson] ||= []).push(q);
  }
  const lessons = Object.keys(mcByLesson).map(Number).sort(function (a, b) { return a - b; });
  const probes = [];
  for (const lesson of lessons.slice(0, 6)) {
    const first = mcByLesson[lesson].slice().sort(function (a, b) {
      return a.id.localeCompare(b.id);
    })[0];
    probes.push({ lesson: lesson, question: first });
  }
  return probes;
}
```

One MC per lesson, first by ID, cap 6 per unit.

## Video URL lookup (use ALL_UNITS_DATA)

```js
function getVideoUrlForLesson(unitNumber, lessonNumber) {
  if (typeof ALL_UNITS_DATA === 'undefined') return null;
  const unit = ALL_UNITS_DATA.find(function (u) { return u.unitId === 'unit' + unitNumber; });
  if (!unit || !Array.isArray(unit.topics)) return null;
  const topicId = unitNumber + '-' + lessonNumber;
  const topic = unit.topics.find(function (t) { return t.id === topicId; });
  if (!topic || !Array.isArray(topic.videos) || topic.videos.length === 0) return null;
  return topic.videos[0].url || topic.videos[0].altUrl || null;
}
```
