## Function specifications (implement these exactly)

### `daysLeft(todayStr, examDateStr)`
- Parse both as `YYYY-MM-DD`.
- Return `Math.max(1, Math.ceil((examDate - today) / MS_PER_DAY))`.
- If today >= exam: return 1 (floor).
- If either string is malformed: return 1.
- Test values: `daysLeft('2026-04-13', '2026-05-07')` → 24. `daysLeft('2026-05-07', '2026-05-07')` → 1. `daysLeft('2026-05-08', '2026-05-07')` → 1.

### `computeDailyDose(remaining, days)`
- Return `Math.min(DOSE_MAX, Math.max(DOSE_MIN, Math.ceil(remaining / days)))`.
- If `remaining <= 0` or `days <= 0`: return `DOSE_MIN` (3).
- Test values: `computeDailyDose(81, 24)` → 4. `computeDailyDose(5, 1)` → 5. `computeDailyDose(0, 24)` → 3. `computeDailyDose(500, 1)` → 12.

### `formulaMastery(formulaId, state)`
- If `state.touchedFormulas && state.touchedFormulas[formulaId] && typeof state.touchedFormulas[formulaId].lastMastery === 'number'`, return `state.touchedFormulas[formulaId].lastMastery`.
- Else return `BKT_INIT` (0.3).

### `formulaWeight(formulaId, state)`
- Look up unit via `FORMULA_UNIT_MAP[formulaId]`. If missing: return 0 (formula won't be picked).
- Look up tier: iterate `window.AP_STATS_CARTRIDGE.commands` for the first entry with matching `id`. If missing: return 0.
- `examWeight = UNIT_EXAM_WEIGHTS[unit] || 0`.
- `tierMult = TIER_MULTIPLIERS[tier] || 0`.
- `mastery = formulaMastery(formulaId, state)`.
- Return `examWeight * tierMult * (1 - mastery)`.
- Spec acceptance: `formulaWeight('phat-sd', untouchedState)` ≈ 0.095 × 4 × 0.7 = **0.266** (within 1e-9).

### `formulaName(formulaId)`
- Look up `window.AP_STATS_CARTRIDGE.commands` for the first entry with matching `id`. Return its `action` string.
- If missing: return `formulaId` as a fallback.

### `touchedFormulaCount(state, tier)`
- Count keys in `state.touchedFormulas` whose cartridge-tier matches the given `tier`.
- Used for the coverage floor check.
- If `state.touchedFormulas` is missing, return 0.

### `pickProbeForFormula(formulaId, state)`
- **Case 1 — supplement probe**: Iterate `window.EMBEDDED_CURRICULUM_SUPPLEMENT` for any entry with `entry.formulaId === formulaId`. If found, prefer one whose `id` is NOT already in `state.units[unit].mcqResults` (untouched). Return `{ formulaId, questionId: entry.id, unit, lesson, tier }`. Derive `unit` and `lesson` by parsing `entry.id` with the regex `/^U(\d+)-L(\d+)-QS?\d+/`. Get `tier` via `AP_STATS_CARTRIDGE.commands[formulaId].tier`.
- **Case 2 — main curriculum probe**: Look up `window.FORMULA_PROBE_MAP.map[formulaId]`. If present and `questionIds` is a non-empty array: prefer an untouched questionId (not already answered in any unit's `mcqResults`), else the first one. Parse unit+lesson from the questionId with the regex `/^U(\d+)-L(\d+)-Q\d+/`. Return `{ formulaId, questionId, unit, lesson, tier }`.
- Return `null` if neither path yields a probe.

### `pickDailyQueue(state, todayStr, examDateStr)`
1. If `state.dailyDose && state.dailyDose.date === todayStr`: return the existing queue (idempotent — don't regenerate mid-day).
2. Compute `days = daysLeft(todayStr, examDateStr)`.
3. Build `allFormulas = Object.keys(FORMULA_UNIT_MAP)`.
4. Split into `touched` (in `state.touchedFormulas`) and `untouched`.
5. Coverage floor check: `coreAndRegularTouched = touchedFormulaCount(state, 'core') + touchedFormulaCount(state, 'regular')`. If `< 32`, mark all untouched core/regular formulas as **priority**.
6. Compute weight for every candidate formula.
7. Build the sorted list: priority-untouched core/regular first (sorted by weight desc), then all other formulas sorted by weight desc. Tie-break by `(−weight, formulaId)` for determinism.
8. Compute `remaining = untouched.length || 81`.
9. `dose = computeDailyDose(remaining, days)`.
10. Walk the sorted list, calling `pickProbeForFormula(formulaId, state)` for each. Keep the first `dose` non-null results. Skip any formula whose `pickProbeForFormula` returns null.
11. Return `{ date: todayStr, queue: [...], completed: [] }`. Each queue item has `{ formulaId, questionId, unit, lesson, tier }`.

### `recordFormulaTouch(formulaId, correct, state)`
- Ensure `state.touchedFormulas = state.touchedFormulas || {}`.
- `const prior = state.touchedFormulas[formulaId] && typeof state.touchedFormulas[formulaId].lastMastery === 'number' ? state.touchedFormulas[formulaId].lastMastery : BKT_INIT;`
- `const next = window.BKT && window.BKT.updateMastery ? window.BKT.updateMastery(prior, correct) : prior;`
- Set `state.touchedFormulas[formulaId] = { firstTouchedAt: state.touchedFormulas[formulaId] ? state.touchedFormulas[formulaId].firstTouchedAt : new Date().toISOString().slice(0,10), lastMastery: next };`
- Return `next`.
