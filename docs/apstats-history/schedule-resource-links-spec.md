# Schedule Resource Links — Spec

## Goal

When a student clicks a schedule cell in `ap_stats_roadmap_square_mode.html`, a System 7-style dialog opens showing linked resources for that day: lesson videos, follow-along worksheets, drills, and Blookets. Resources are pulled from the existing `units.js` data file.

## Data Source

**File:** `../curriculum_render/data/units.js`
- Exports `ALL_UNITS_DATA` — array of 9 unit objects
- Each unit has `topics[]`, each topic has:
  - `id`: e.g. `"6-2"`, `"4-1"`
  - `videos[]`: `{ url, altUrl }` — AP Classroom + Google Drive mirror
  - `blookets[]`: `{ url, title }` — Blooket sets and lrsl-driller apps
  - `pdfs[]`: `{ url, label }` — worksheets, follow-alongs (some are live HTML apps)

## Schedule Data Mapping

The schedule array `S` has entries like:
```js
[2026, 2, 9,
  d("6.6", "Concluding Test for p", 6, "Quiz 6.4", "Drills 6.6, Quiz 6.5"),
  d("6.7", "Type I & II Errors", 6, "Quiz 6.5", "Drills 6.7, Quiz 6.6")]
```

The `d()` fields are: `t` (topic code), `n` (name), `u` (unit), `due`, `as` (assigned), `db` (double).

**Topic code → units.js lookup:**
- `t = "6.6"` → topic id `"6-6"` in unit 6
- `t = "7.1+7.2"` (double day) → look up both `"7-1"` and `"7-2"`
- `t = "Review"` → no topic lookup (review days have no direct resources)

**Due/Assigned field parsing:**
- `"Quiz 6.4"` → look up topic `"6-4"`, show its Blooket links
- `"Drills 6.6"` → look up topic `"6-6"`, show its lrsl-driller links
- `"Drills 6.6, Quiz 6.5"` → comma-separated, parse each token
- `"U6 PC"` → unit practice check — no units.js mapping (skip for now)
- Fields may contain items that don't map to units.js — skip gracefully

## UI: System 7 Detail Panel

Reuse the existing `showDialog()` pattern but with richer content.

### Trigger
- Click on any schedule cell that has lesson data (not OFF, NC, EX, PO)
- Click handler on `.dc` cells in `rCal()`

### Panel Content

**Header:** `"Mar 9 — 6.6: Concluding Test for p"`

**Sections (shown only if resources exist):**

1. **Today's Lesson**
   - Video links (numbered if multiple): `"Video 1"`, `"Video 2"` — open AP Classroom URL
   - Alt link (Google Drive mirror) shown as smaller secondary link
   - Follow-along worksheet (from `pdfs[]` where label contains "Follow-Along" or URL points to github.io live worksheet)
   - Hide teacher-only materials (answer keys, teacher keys)

2. **Due Today** (parsed from `due` field)
   - Quiz links → Blooket URLs from the referenced topic
   - Skip items that don't resolve to units.js

3. **Assigned Today** (parsed from `as` field)
   - Drill links → lrsl-driller URLs from the referenced topic
   - Quiz links → Blooket URLs from the referenced topic
   - Skip items that don't resolve (like "U6 PC")

### Link Behavior
- All links open in new tab (`target="_blank"`)
- Links styled as classic Mac underlined blue text

### Panel Style
- Reuse existing `.dialog-overlay` / `.dialog-box` System 7 chrome
- Close button: existing dialog close pattern
- No sound effect on open (keep it lightweight)
- Width: ~320px to fit resource lists

## Data Loading

`units.js` uses `export const ALL_UNITS_DATA = [...]`. Since the roadmap is a single HTML file (no build system), we need to inline or fetch the data.

**Approach:** Build a static lookup table `RESOURCES` directly in the HTML, extracted from units.js. Structure:

```js
const RESOURCES = {
  "6-6": {
    videos: [{ url: "...", altUrl: "..." }],
    blookets: [{ url: "...", title: "..." }],
    pdfs: [{ url: "...", label: "..." }]
  },
  // ... all topics
};
```

This avoids cross-origin fetch issues and keeps the single-file pattern. The table can be generated by a script or manually extracted.

## Scope

### In scope
- Click-to-open detail panel on schedule cells
- Resource links from units.js (videos, blookets, drills, PDFs)
- Topic code parsing (single and double days)
- Due/assigned field parsing for quiz and drill references
- Student-facing only (hide answer keys, teacher materials)
- New tab for all external links

### Out of scope (for now)
- External quiz/drill URLs not in units.js (Delta Math, etc.)
- "U6 PC" and other non-topic references
- Teacher view toggle
- Resource completeness for units 7-9 (link what exists)

## Edge Cases

- **Double topic days** (`"7.1+7.2"`): Show resources for both topics, grouped
- **Review days**: Show panel with just "Review: U1-5" header, no resource links
- **Missing data**: Topic exists in schedule but not in units.js → show cell info only, no links
- **OFF/NC/EX/PO cells**: No click handler, no panel
- **Empty due/as fields**: Omit those sections from panel
