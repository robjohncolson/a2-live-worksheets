## §1 — Non-negotiables (every task, no exceptions)

1. **The grade row is frozen.** `gradebookClient.record({source:'worksheet', itemId:'BL-U{u}-L{key}-DESK_DONE', unit, topic, response:{selfAttest:'blooket'}, score, attempt:1})`. `Flashcards.blooketItemId()` output, `_blooketCommit`, `_studentMarkSave`, `_fcCommit`'s payload, and `roster-server/**` are **not edited** by any task in this build. Never mint another `*-DESK_DONE` id.
2. **Caps + thresholds stay literal:** `const BLOOKET_PASS_THRESHOLD = 0.80;` and `const BLOOKET_FULLDECK_SECONDS = 40;` in the Desk; `PASS_THRESHOLD`/`FULLDECK_SECONDS`/`QUICK_TARGET` in `flashcards.js`. Quick check commits **only on pass**; full timed deck **always** commits; credit ladder 1 / ⅔ / ⅓ / 0 unchanged.
3. **Parity discipline.** `tests/flashcards-engine.test.js` extracts the Desk's inline `_bf*`/`_ft*` bodies by `function NAME(` brace-matching and asserts output parity with `flashcards.js`. Therefore: (a) never rename or convert those inline functions to arrow/const form; (b) any change to `flashcards.js` lands **in the same task** with the identical inline twin in the Desk plus a new parity `it(...)`; (c) prefer **new sibling modules that both surfaces load** over growing `flashcards.js`.
4. **Existing static pins must stay true.** `tests/desk-blooket-flashcards.test.js` (54 its), `tests/desk-timed-deck.test.js` (26 its), `tests/mobile-home-flashcards.test.js`, `tests/mobile-home-fc-csv-fallback.test.js`, `tests/desk-view-as.test.js`, `tests/feeder-bestwins-invariants.property.test.js`, `tests/desk-modal-polish.test.js`, `tests/desk-completion-gate.test.js`. Concretely: keep `_bfLoadProgress`'s `(entry.idx || 0) >= entry.deck.length` guard; keep the `if (passed` gate in `_bfFinish` with no `_blooketCommit`/`_bfClearProgress` token before it; keep `_bfCloseUI` removing both keydown handlers + `_ftClearTimer()` + `_ftState.round = null`; keep `_bfKeydownHandler`'s guards; keep the picker literals `Quick check` and `Full deck`; keep mobile `_fcCommit` **synchronous** (returns an object, never awaits).
5. **Storage keys stay:** `apstats_desk_bf_progress_<email>` (quick resume), `apstats_srs_log_<email>` (per-card log; **additive fields only**, cap 2000), `apstats_mobile_fcbest_v2`. New keys are listed in §3.
6. **View-as / read-only.** Every new localStorage writer short-circuits when `_viewAsContext()` returns non-null (Desk) and never writes under `window.__WS_READ_ONLY__`. Every reference to a Desk global from inside a function that tests execute in isolation must be `typeof`-guarded (`typeof _viewAsContext === 'function' && _viewAsContext()`).
7. **Content is sacred.** No task edits any `*_blooket.csv`, `data/blooket-difficulty.json`, `data/skill-map*.json`, `data/skill-taxonomy-ced2026.json`, or anything under `curriculum_render`. Lint findings are reports, never edits.
8. **No AI-authored text reaches students.** Difficulty `rationale` strings are never rendered. Any student-facing explanatory text must come from a file with `"provenance": "teacher"` (none exist yet → render nothing).
9. **Vocabulary:** student-facing copy never uses old CED codes (VAR-/UNC-/DAT-). Say "Blooket half of Done (the worksheet 60% is also needed)", not "unlocks the lesson".
10. **No git commits, no pushes, no test runs** from Codex tasks. Write only within owned paths.
11. **Code style (CLAUDE.md):** skimmable, early returns, no cleverness; ES5-style `function NAME(` declarations inside the Desk/mobile inline scripts (they run without a build step and the tests brace-match by name).

## §3 — New storage / data contracts

- **Cross-surface resume:** the quick resume record `apstats_desk_bf_progress_<email>` is shared by both surfaces; `misses` entries use the Desk field names `{ qnum, q, correctAnswer }` (readers tolerate legacy `stem`); `roundId`/`seq` are reused only when the roundId prefix equals the current surface — otherwise mint a fresh `<surface>-…` id and reset `seq` to 0.
- **Per-card log entry (extends the existing `apstats_srs_log_<email>` shape, additive):**
  `{ topic, qnum, correct, latencyMs, wasTimeout, missIndex, ts,  mode:'quick'|'full'|'review', csv:'u4_l1_l2_blooket.csv', surface:'desk'|'mobile', roundId:'<surface>-<ts>-<rand4>', seq:<int from 0 within round>, nChoices:<int>, chosenIdx:<int|-1 for timeout>, review?: 'again'|'hard'|'good'|'easy', stemHash?: '<8 hex djb2 of the normalized stem — writers SHOULD include it>', displayedPerm?: [<int>] }`.
  `csv` is the deck's basename (from `_bfCsvPath(topic)` on the Desk / `Flashcards.csvPathFromWorksheet(url)` on mobile). Cap stays 2000 (drop oldest). Existing entries lacking the new fields must keep parsing (readers treat missing `mode` as `'full'`, missing `surface` as `'desk'`).
- **Email key derivation** (must be identical on both surfaces): Desk `getStudentEmail()` = `localStorage.apstats_desk_student_email` if set (both surfaces write the BARE username there on roster sign-in), else `rosterClient.current().username + '@roster.local'`. Mobile `_fcEmail()` MUST mirror that exact order (legacy key first, then username@roster.local). Not signed in and no legacy key → do not write.
- **SRS folded state:** `apstats_fc_state_v1_<email>` → `{ version:1, cards:{ '<csv>#<qnum>': { ease:2500, intervalDays:0, dueDay:<int day index>, reps:0, lapses:0, lastGrade:'good', lastTs, stemHash|null } }, seen:[<entry keys already folded>], tombstones:{}, updatedAt }`. `stemHash` may be null/absent (legacy log entries) — readers must tolerate it. Day index = `Math.floor(ts / 86400000)` (UTC days). Written only by `lib/flashcard-store.js` via an injected storage adapter.
- **Flags file:** `data/flashcard-flags.json` →
  `{ "version":1, "flags": { "reviewMode": { "enabled": false, "allowUsernames": [], "allowSections": [], "urlParam": "fcReview" }, "dueTodayDeck": {...same shape...}, "choicePermutation": { "enabled": true, ...same shape..., "killSwitchKey": "apstats_fc_perm_off" }, "readinessBadge": {...}, "quickRetryRedraw": {...} } }`.
  Resolution order (pure `lib/flashcard-flags.js`): killSwitchKey present in localStorage with value `'1'` → OFF regardless; else URL param **exactly** `?<urlParam>=1` → ON (any other value is ignored — students must not be able to turn a flag OFF via URL); else `allowUsernames` contains current username → ON; else `allowSections` contains current section → ON; else `enabled`. `loadFlags` resolves to `{ version:0, flags:{} }` on ANY failure including a parseable response without a `flags` object. Fetched with `{cache:'no-cache'}` + `?v=<BUILD>` query.
- **Passport export:** `{ format:'apstats-flashcards', version:1, exportedAt, email, payload:{ state:<folded state>, log:<srs log> } }`. Import **unconditionally** refuses a different `email` (no override option exists), previews counts before commit.
