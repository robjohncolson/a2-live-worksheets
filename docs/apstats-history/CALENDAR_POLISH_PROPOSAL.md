## Read-the-code verification

Before ranking anything the workflow read the real CSS (lines 488–672), `cls()`/`htm()` (16160–16184), the nav bar, and the frozen test file. Several "obvious" fixes turned out to be **wrong against the real code** and were demoted. Verified facts that shaped this plan:

- **`htm()` renders the date `<div class="dn">` as the FIRST child** of every cell — so the **top-left corner is the date's home, not free space**. Every "put a glyph in the top-left" idea collides with the date and was demoted.
- **`.cal-nav` has exactly TWO children** (prev/next) with `justify-content: space-between`, and uses a `visibility:hidden` `.cal-nav-hidden` toggle specifically to *keep the corner slot* so an arrow doesn't drift to the middle on edge pages. Inserting a centered third child (a "Today" button / context label) **re-distributes the flex and pulls both arrows inward** — an unflagged visual regression. Demoted.
- **`.cell-today` is `inset … 2px`; all state rings are `3px`.** That thin-vs-thick contrast is a deliberate hierarchy cue. Flattening today to 3px works *against* cohesion. Demoted.
- **`.dc:hover` is a full black invert** that momentarily **wipes every state overlay** (done greyscale, amber/green rings) into solid black. No first-pass item named this; it is the single biggest *felt* incoherence. Promoted to a top decision (item 8).
- **Frozen test A1** requires `grayscale[^}]*opacity` inside the `.dc-done`/`.dc-localdone` rules — but it is **value-agnostic**, so replacing the literal `0.6` with `var(--cell-done-dim)` keeps it green. Verified.
- **`updateLegend`, `rProg`, and `rCD` are referenced by NO test file** — genuinely unpinned and safe to extend.

## Needs your nod — higher-impact / feel-changing / frozen-test items

### 8. Make hover ADDITIVE — the biggest felt incoherence
```
 current hover:                 additive hover (option B):
 ┌──────────┐                   ┌──────────┐
 │██████████│  ← solid black,   │░ 1.2 ░░░░│  ← inset highlight,
 │██████████│    every ring     │░ Distr. ░│    rings + pastel
 │██████████│    and pastel     │░░░░●░░░░◐│    still visible
 └──────────┘    gone           └──────────┘
```
`.dc:hover` flips to full black and wipes the greyscale-done dim, the amber/green rings, and the unit pastel into one black square; only the dots survive as stranded color. Reworking hover to a **subtle inset highlight that layers on top** preserves every state cue. **Choose:** (A) keep invert, (B) additive inset highlight *(recommended)*, (C) invert only plain cells. The summer-week hover (lines 668–670) must track the choice.

### 9. Synthwave next-up reconciliation
The `.cal-current` neon (cyan + magenta, pulsing to a 22px bloom) is the loudest, most palette-alien element — and it is a **frozen contract** (`#ff2e97`, `calCurrentPulse`, the keyframes, reduced-motion, old-outline-gone). **Choose a default:** (A) keep, (B) tone amplitude ~40% + slow to 2.2s, (C) **marching-ants** 1px dashed black selection *(most classic-Mac)*, (D) **gold** to unify with `dc-ahead`. Options B/C/D as the default = a frozen-test rewrite PR. **Safe preview path I can ship without your nod:** a `data-calcur` localStorage toggle adding the alternatives *after* the pinned rules (default unchanged, all 46 green) so you can see ants/tone/gold live first.

### 10. Date-aware corner grammar (resolves the two real collisions)
```
 TOP-LEFT = date (FIXED, htm renders .dn here)      TOP-RIGHT = today OR lock
 ┌────────────────────────────┐                     (the other dropped/offset)
 │ 9            ◀TODAY / 🔒    │
 │ 1.2 Describing…            │
 │ ●            2x        ◧    │ ← BOTTOM: status-dot (L),
 └────────────────────────────┘   2x badge (CENTER), poll-dot (R)
```
Two confirmed overlaps: lock vs TODAY (both top-right) and 2x vs poll-dot (both bottom-right). The first-pass "move lock to top-left" is **VETOED** — the date lives there. Recommended: move `.dbl` to bottom-**center** (static `translateX(-50%)`); resolve the top-right pair by **dropping the redundant TODAY chip** (the inset border already signals today) or offsetting the lock to stack. **Choose:** (A) dbl→center, keep lock top-right, drop/shrink TODAY chip; (B) dbl→center, stack the two top-right badges; (C) full grammar. Coordinate with items 11/15 — they all want the same corners; do them in ONE pass.

### 11. Colorblind shape glyphs (shared vocabulary)
Partial amber vs done green is invisible to ~8% of boys; next-up neon can read as grey. Add black/inherited `::before` glyphs (✓ done, ◐ partial, ▶ next-up) that survive the greyscale filter, reusing the **exact symbols sTip already uses** so legend, tooltip, and grid share one set. Placement depends on item 10 (date owns top-left) — design together. Needs a visual pass so glyphs don't sit under the cell-today border.

### 12. Mobile legibility
At ≤700px `.dc .tt{display:none}` hides the subtitle AND touch has no hover tooltip, so a phone student (majority device) can't decode locked/done/next-up at 40px. Clamp the subtitle to one truncated line instead of hiding it; optionally add touch-only state glyphs and bump min-height 40px→46px. One real-device check before shipping.

### 13. Honest pace-aware progress
`#pl` reports % of **dates elapsed** — it climbs even if the student did nothing. Replace with a real completion comparison ("On pace" / "N ahead" / "N to catch up") from the **same oracle the calendar trusts**, plus a darkening done-fill per segment (no new hue). **Risk to mitigate first:** `localLessonState` → `_isLessonComplete` reads `/grade` caches that are **not warm at first rCal**, so the count must recompute on the `renderDoNowGrades` repaint and fail open to a neutral label, or it shows a wrong "N to catch up" that self-corrects (looks broken).

### 14. Fix the dead tooltip links
Real bug: `.tip{pointer-events:none}` (line 696) means the Worksheet/Quiz/Blooket/Schoology anchors sTip injects **can never be clicked**. **Choose:** (A) make the tooltip an honest hover-only INFO surface — drop the dead anchors, add "Click to open · double-click for grade", keep the status lines *(recommended, least regression)*; (B) `pointer-events:auto` + a hover-bridge to keep links live (more surface). Links already work via the cell click + day-grade modal.

### 15. Calm monochrome today heartbeat
Today is the temporal anchor but quieter than the two existing pulses. A 2.4s monochrome breathe would re-seat it — but it would be a **third idle animation** on a grid you already find too busy, and classic System-7 had zero ambient motion. **VETOED from auto-ship on feel.** Choose: skip (recommended), add the breathe, or seat today forward statically.

### 16. One-ring priority — keep today at 2px
A priority cascade (today/next-up > ahead > done > partial) via compound selectors appended *after* the pinned bare rules is test-safe. But the first-pass plan to **also bump today 2px→3px is a regression** — the thin-vs-thick contrast is the cue that seats today apart. Choose: skip, add the cascade keeping today at 2px *(recommended)*, or unify to 3px *(not recommended)*. Needs a cross-browser look (greyscale+box-shadow compositing varies).
